How to add this listing to your VCC

Hit Add to VCC and your browser hands the listing straight to the Creator Companion. If nothing happens, add it by hand:

  1. Open the VCC and go to Settings
  2. Click the Packages tab
  3. Click Add Repository
  4. Paste the URL below
  5. Click Add
  6. Check the repository info, then click I Understand
  7. Open any project to see the packages from this listing
